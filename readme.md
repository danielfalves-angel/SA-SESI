# SA-SESI

# O que é

O sistema serve basicamente para monitorar sensores. Além disso, o úsuario do sistema também pode cadastrar sensor, editar o sesnsor ou excluir o sensor.

Nome do sensor (ex: Mark)
Rota (ex: 645)
Unidade de medida (ex: °C, km/h, kg, etc.)
Valor (ex: 100km/h)
Status (ex: funcionando, manutenção, etc.)

# Linguagens usadas

HTML
CSS
JavaScript
PHP

# Como rodar o projeto

1- Instalar o XAMPP
2- Colocar os arquivos do projeto na pasta htdocs do XAMPP
3- Iniciar o Apache e o MySQL pelo painel do XAMPP
4- Acessar o site pelo navegador
